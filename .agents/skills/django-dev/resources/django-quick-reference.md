# Django Quick Reference & Command Cheat Sheet

---

## 1. CLI Commands (`manage.py`)

| Command | Description |
| :--- | :--- |
| `python manage.py runserver [port]` | Launches the local development server (default port 8000). |
| `python manage.py startapp <app_name>` | Scaffolds a new Django app directory structure. |
| `python manage.py makemigrations [app]` | Inspects models and writes new migration files. |
| `python manage.py migrate [app] [migration]`| Executes pending migrations on the database. |
| `python manage.py showmigrations` | Lists all migrations and their current applied status `[X]`. |
| `python manage.py sqlmigrate <app> <num>` | Shows the exact SQL queries generated by a migration. |
| `python manage.py createsuperuser` | Prompts to create an administrative user. |
| `python manage.py shell` | Launches an interactive Python REPL with Django loaded. |
| `python manage.py test [app.tests]` | Executes unit and integration test suites. |
| `python manage.py collectstatic --noinput` | Gathers all static files into `STATIC_ROOT`. |
| `python manage.py check --deploy` | Scans `settings.py` for security misconfigurations. |

## 2. ORM Field Lookup Operators

```python
# Exact & Case-Insensitive Matching
Model.objects.filter(name__exact="Camisa")
Model.objects.filter(name__iexact="camisa")

# Partial String Matching
Model.objects.filter(title__contains="Pro")
Model.objects.filter(title__icontains="pro")

# Numeric & Date Comparisons
Model.objects.filter(precio__gt=100)       # Greater than
Model.objects.filter(precio__gte=100)      # Greater than or equal to
Model.objects.filter(precio__lt=50)        # Less than
Model.objects.filter(precio__lte=50)       # Less than or equal to
Model.objects.filter(creado_en__year=2026) # Date part extraction

# Inclusion & Nullability
Model.objects.filter(estado__in=["PB", "AR"])
Model.objects.filter(creado_por__isnull=True)
Model.objects.filter(fecha__range=[inicio, fin])
```

## 3. Template Engine Reference

### Template Tags
- `{% extends "base.html" %}`: Inherits markup from a base layout.
- `{% block content %}{% endblock %}`: Defines an overrideable block.
- `{% if condition %} ... {% elif other %} ... {% else %} ... {% endif %}`: Conditionals.
- `{% for item in items %} ... {% empty %} ... {% endfor %}`: Iteration with fallback.
- `{% url 'app_name:view_name' param1 %}`: Reverses a named URL pattern.
- `{% csrf_token %}`: Renders a hidden CSRF token input in forms.
- `{% static 'css/style.css' %}`: Resolves static file URLs.
- `{% include "partials/_card.html" %}`: Inlines a partial template.

### Common Template Filters
- `{{ text|lower }}` / `{{ text|upper }}`: Case transformation.
- `{{ date_val|date:"d/m/Y H:i" }}`: Date formatting.
- `{{ value|default:"N/A" }}`: Fallback for empty/null values.
- `{{ list_val|length }}`: Count elements.
- `{{ description|truncatewords:20 }}`: Truncate by word count.
- `{{ price|floatformat:2 }}`: Format decimal precision.
- `{{ html_string|safe }}`: Disables auto-escaping (use ONLY with trusted input).
