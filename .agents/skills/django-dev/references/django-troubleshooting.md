# Django Diagnostic & Troubleshooting Matrix

A comprehensive runbook for debugging common runtime exceptions, migration errors, and configuration pitfalls in Django applications.

---

## 1. Quick Diagnostic Matrix

| Exception / Symptom | Root Cause | Immediate Resolution |
| :--- | :--- | :--- |
| `OperationalError: no such table: ...` | Migrations have not been applied to the database. | Run `python manage.py migrate`. If it's a new model, run `makemigrations <app>` first. |
| `TemplateDoesNotExist: ...` | Template path mismatch, or app missing from `INSTALLED_APPS`, or `APP_DIRS: False`. | 1. Ensure app is in `INSTALLED_APPS`.<br>2. Check `TEMPLATES["DIRS"]` in `settings.py`.<br>3. Verify relative path matches `core/templates/core/name.html`. |
| `CSRF verification failed. Request aborted.` | Missing `{% csrf_token %}` tag, untrusted origin header, or cross-domain proxy. | 1. Include `{% csrf_token %}` inside `<form method="post">`.<br>2. For HTTPS reverse proxies, add domain to `CSRF_TRUSTED_ORIGINS`. |
| `IntegrityError: UNIQUE constraint failed` | Attempted to insert a duplicate value for a `unique=True` field or primary key. | Validate form input with clean methods, or handle via `get_or_create()` with `defaults`. |
| `IntegrityError: NOT NULL constraint failed` | Model field was added without `default`, `null=True`, or provided initial value. | Supply a default value in the model definition, or create a data migration. |
| `RelatedObjectDoesNotExist` | Accessed a `OneToOne` or `ForeignKey` field configured with `null=True` that holds no relation. | Check `if hasattr(obj, 'relation') and obj.relation:` before property access. |
| `MultipleObjectsReturned` | `.get()` query matched 2 or more rows in the database. | Refine filter criteria to guarantee uniqueness, or use `.filter(...).first()`. |
| `DoesNotExist` | `.get()` query found zero matching records. | Use `get_object_or_404(Model, ...)` inside views, or wrap query in `try...except Model.DoesNotExist:`. |
| `CommandError: Conflicting migrations detected` | Two developers created parallel migrations with identical dependency numbers on different branches. | Run `python manage.py makemigrations --merge` and review the resulting merge file. |
| `AppRegistryNotReady: Apps aren't loaded yet` | Attempting to import models at the module level before Django initialized (e.g. in `__init__.py` or early in `settings.py`). | Move model imports inside functions or into `ready()` method of `AppConfig`. |

## 2. In-Depth Troubleshooting Workflows

### Resolving Migration Conflicts
When merging git branches with concurrent schema changes:
```bash
# 1. Detect conflict
python manage.py migrate
# Output: CommandError: Conflicting migrations detected; multiple leaf nodes in the migration graph: (0002_add_stock, 0002_add_status in core).

# 2. Automatically generate merge migration
python manage.py makemigrations --merge

# 3. Apply merged migrations
python manage.py migrate
```

### Resetting or Inspecting Migrations
```bash
# View all migration application status (checked = applied, [ ] = pending)
python manage.py showmigrations

# View the raw SQL generated by a specific migration without applying it
python manage.py sqlmigrate core 0002

# Roll back an app to a specific migration
python manage.py migrate core 0001

# Completely unapply all migrations for an app
python manage.py migrate core zero
```

### Debugging CSRF in APIs & Forms
- **Standard Forms**: Always ensure `<form method="post">` contains `{% csrf_token %}` right after the opening tag.
- **AJAX / Fetch**: Pass the CSRF token in the request header:
  ```javascript
  const csrftoken = document.querySelector('[name=csrfmiddlewaretoken]').value;
  fetch('/api/endpoint/', {
    method: 'POST',
    headers: {
      'X-CSRFToken': csrftoken,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(data),
  });
  ```
- **DRF Endpoints**: Use token-based or JWT authentication (`rest_framework.authentication.TokenAuthentication`, SimpleJWT) instead of session authentication for stateless public/mobile APIs to bypass CSRF requirements.
