# Django Caching Strategies, Signals, and Middleware Patterns

---

## 1. Caching Strategies

### View-Level Caching
Caches the entire HTTP response generated by a view:
```python
from django.views.decorators.cache import cache_page
from django.utils.decorators import method_decorator
from django.views.generic import ListView

# For Function-Based Views (FBV)
@cache_page(60 * 15)  # Cache for 15 minutes
def product_list(request):
    ...

# For Class-Based Views (CBV)
@method_decorator(cache_page(60 * 15), name='dispatch')
class ProductListView(ListView):
    ...
```

### Template Fragment Caching
Caches expensive sub-sections of a template (e.g. navigation trees, sidebars):
```django
{% load cache %}

{# Cache sidebar for 500 seconds keyed by user status #}
{% cache 500 sidebar request.user.is_authenticated %}
    <nav class="sidebar">
        <!-- Expensive database rendering -->
    </nav>
{% endcache %}
```

### Low-Level Caching (`django.core.cache`)
Direct key-value caching for query results, API responses, or calculated metrics:
```python
from django.core.cache import cache
from apps.products.models import Product

def get_featured_products():
    cache_key = 'featured_products_list'
    products = cache.get(cache_key)

    if products is None:
        products = list(Product.objects.filter(is_featured=True).select_related('category')[:10])
        cache.set(cache_key, products, timeout=60 * 15)  # 15 minutes

    return products
```

## 2. Django Signals Architecture

Signals allow decoupled applications to get notified when actions occur elsewhere in the framework.

### Recommended Pattern: Signals in Dedicated Module
Always place signals in `signals.py` inside the app, and import them inside `AppConfig.ready()` to prevent premature model loading.

```python
# apps/users/signals.py
from django.db.models.signals import post_save
from django.dispatch import receiver
from django.contrib.auth import get_user_model
from .models import Profile

User = get_user_model()

@receiver(post_save, sender=User)
def create_or_save_user_profile(sender, instance, created, **kwargs):
    """Ensures a 1:1 Profile exists for every User."""
    if created:
        Profile.objects.create(user=instance)
    else:
        if hasattr(instance, 'profile'):
            instance.profile.save()
```

Connect inside `apps/users/apps.py`:
```python
from django.apps import AppConfig

class UsersConfig(AppConfig):
    default_auto_field = 'django.db.models.BigAutoField'
    name = 'apps.users'

    def ready(self):
        # Implicitly connects @receiver signals on startup
        import apps.users.signals
```

## 3. Custom Middleware

Middleware intercepts every HTTP request before reaching views, and every HTTP response before leaving the server.

```python
# middleware/request_logging.py
import time
import logging

logger = logging.getLogger('django.request')

class RequestLoggingMiddleware:
    """Measures request duration and logs HTTP metrics."""

    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        # Code executed before view
        start_time = time.time()

        response = self.get_response(request)

        # Code executed after view
        duration = time.time() - start_time
        logger.info(
            f"{request.method} {request.path} - Status: {response.status_code} - Duration: {duration:.3f}s"
        )

        return response
```
